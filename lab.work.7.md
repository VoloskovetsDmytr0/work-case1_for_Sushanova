# 📌 Завдання 3: Власний сценарій

## 🔧 Код скрипта

```bash
#!/bin/bash

echo "Введіть число:"
read num

if [ $num -gt 0 ]; then
    echo "Число додатнє"
elif [ $num -lt 0 ]; then
    echo "Число від’ємне"
else
    echo "Це нуль"
fi

echo "Лічильник від 1 до 5:"
for i in {1..5}
do
    echo "Число: $i"
done
```

# 📚 Контрольні запитання

---

## ❓ В чому відмінність між командами `arch` та `lscpu`?

Команда `arch` виводить лише архітектуру системи (наприклад, x86_64).
Команда `lscpu` надає детальну інформацію про процесор: кількість ядер, частоту, модель, кеш та інші характеристики.

---

## ❓ Якою командою можна отримати інформацію про стан використання RAM?

```bash
free -h
```

Ця команда показує використану, вільну пам’ять та swap.

---

## ❓ Як у скриптах працювати зі змінними, умовами та циклами?

### Змінні

```bash
name="Dima"
echo $name
```

### Умови

```bash
if [ умова ]; then
    команда
fi
```

### Цикли

```bash
for i in {1..5}
do
    echo $i
done
```

---

## ❓ Які команди для перегляду периферійних пристроїв?

* `lsusb` — USB пристрої
* `lspci` — PCI пристрої
* `lsblk` — накопичувачі
* `dmesg` — системні повідомлення
* `hwinfo` — детальна інформація (якщо встановлено)

---

## ❓ Які можливості GParted?

GParted — це графічний інструмент для роботи з розділами диска.

### Основні можливості:

* створення розділів
* видалення розділів
* зміна розміру
* форматування (ext4, NTFS, FAT32)
* керування файловими системами
